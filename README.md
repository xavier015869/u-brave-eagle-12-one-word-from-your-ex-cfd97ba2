One Word From Your Ex — a make.fun bounty entry by [@xavier015869](https://make.fun/r/9d3wsaqp).

## The entry

Exactly one word, the word my ex would use to describe me:

**Exhausting**

It is the blunt verdict an ex actually delivers — not an insult for its own
sake, but the painfully honest summary of dating someone who never switches
off. It lands instantly, it stings because it is true, and anyone who has
lived through a relationship like that recognises it at once.

## How it works

`main.ts` (Node 22) writes that single word — and nothing else, no trailing
newline, no extra whitespace — to `/output/entry.txt`, which the sealed
scorer gates at 1–24 UTF-8 characters. The program first checks the word
itself against that gate before writing it.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
